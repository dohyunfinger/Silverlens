# SilverLens

**사투리와 음식 사진을 이해해, 먹는 사람에게 맞는 식품 안전 정보를 알려 주는 AI 서비스**


저희는 기술의 속도보다 어르신의 걸음에 발을 맞추기로 한 **우승에 동의** 팀입니다. 새로운 AI 기술을 볼 때마다 '우리 할머니, 할아버지도 이걸 잘 쓰시면 좋겠는데' 하는 생각을 자주 했습니다. 그렇게 막연히 프로그램을 기획했지만, '이게 진짜 어르신의 삶에 도움이 될까?'라는 의문에 노트북을 덮고 일주일간 어르신들의 일상을 관찰했습니다. 그리고 저희의 시선이라는 렌즈 안에서는 보이지 않던 장벽을 발견했습니다. 어르신이 기술을 못 쓰시는 게 아니라, 기술이 어르신의 삶을 배려하지 않았을 뿐이었습니다. 사람을 소외시키는 기술은 완성된 기술이 아니라 생각했습니다. 그래서 저희는 디지털 소외를 지우는 가장 따뜻한 빛이 되고 싶어 대회에 참가했습니다.

> **SilverLens는 사투리와 생활 언어, 음식 사진, 건강 정보를 함께 이해하여 디지털 접근성·언어 이해·식품 안전성의 장벽을 낮추는 시니어 맞춤형 AI 건강 식생활 서비스입니다.**

# 농수산·식품 분야에서 SilverLens의 자리

**식품 안전은 보통 생산과 유통에서 끝납니다. 그런데 안전하게 길러 안전하게 배송된 식품도, 먹는 사람에 따라서는 위험해집니다.**

신장질환이 있는 어르신에게 바나나는 칼륨 때문에 위험하고, 연하장애가 있는 어르신에게 떡은 질식 위험이 있습니다. 통풍이 있는 분께 곱창은 퓨린 때문에 조심해야 할 음식입니다. 하지만 이 정보는 어디에도 붙어 있지 않습니다. 성분표에는 "먹는 사람"이 없기 때문입니다.

SilverLens는 **밥상에 오르는 마지막 한 걸음**을 다룹니다. 생산 단계의 품질 검사가 "이 식품이 안전한가"를 묻는다면, SilverLens는 "이 식품이 **이 사람에게** 안전한가"를 묻습니다.

## 세 축에서의 기여

| 축 | SilverLens의 기여 |
| --- | --- |
| **안전** | 질병 41종·알레르기 46종을 기준으로 위험 식품을 먼저 경고합니다. 21개 안전 원칙과 123종의 위험 식품 목록을 코드가 직접 대조해, AI가 위험을 낮게 판단해도 경고가 사라지지 않게 보장합니다 |
| **가치** | 지역에서 쓰는 식재료 이름(정구지·무시·미깡)을 표준어와 연결해, 시장과 밥상의 언어로도 식품 정보에 닿을 수 있게 합니다. 낯설어서 손이 가지 않던 식재료를 쉬운 우리말로 풀어 소비의 문턱을 낮춥니다 |
| **생산 연계** | 생산·양식 단계는 다루지 않습니다. 대신 소비 단계에서 어떤 식재료가 어떤 건강 조건에서 걸리는지를 데이터로 남겨, 앞 단계로 되돌려 줄 수 있는 형태로 관리합니다 |

저희는 **푸드테크 중에서도 식품 안전 정보의 마지막 전달 지점**에 집중했습니다.

## 왜 시니어인가

식품 안전 사고의 결과가 가장 무거운 집단이기 때문입니다. 씹고 삼키는 힘이 약해지면 같은 음식이 질식 위험이 되고, 만성질환을 여러 개 가진 경우 식품과 약이 부딪힙니다. 동시에 정보에 닿기는 가장 어렵습니다. 작은 글씨의 성분표를 읽기 어렵고, 검색창에 타이핑하기 어렵고, 사투리로 물으면 알아듣지 못합니다.

즉 **위험은 가장 크고 정보 접근은 가장 어려운 지점**입니다. 여기서 AI가 만드는 차이가 가장 큽니다.

# 기획 배경

SilverLens는 디지털 기술 발전 속에서 건강 식생활 정보 접근에 어려움을 겪는 시니어를 위해 기획된 AI 서비스입니다.

많은 시니어는 작은 글씨, 복잡한 화면, 어려운 입력 방식으로 인해 디지털 서비스를 이용하는 데 어려움을 겪습니다. 또한 사투리와 생활 언어를 사용하는 경우 기존 AI가 질문을 정확하게 이해하지 못하거나, 검증되지 않은 건강 정보를 접할 위험이 있습니다.

관찰에서 저희가 실제로 본 장벽은 이런 모습이었습니다. **둔해진 손끝으로 작은 스마트폰 자판을 입력하는 어르신들에게 타이핑은 거대한 벽이었습니다.** 답답한 마음에 자판 대신 음성 인식을 켜 보아도, 기존 AI들은 평생 삶의 흔적이 묻어난 깊은 사투리와 시장 언어(정구지, 정종 등)를 단지 '표준어가 아니다'라는 이유로 알아듣지 못하고 인식 오류만 냈습니다. 게다가 마트나 미디어에 쏟아지는 '로즈마리'나 '아보카도' 같은 낯선 외국 식재료들의 이름 앞에서 선뜻 손을 뻗지 못하고 망설이셨고, 인터넷에 떠도는 건강 정보를 무조건 신뢰하며 많이 먹을수록 좋다고 믿으시는 위험한 상황도 보았습니다.

> **기술의 속도가 노년의 걸음보다 빨라질 때, <br>어르신들은 기술을 거부하는 것이 아니라 기계 앞에서 서글픈 좌절감을 느끼고 계셨습니다. <br>어르신들이 기술을 못 쓰시는 게 아니라, 현재의 기술이 어르신들의 삶을 배려하지 않고 있었습니다.**

SilverLens는 기술이 사용자에게 맞춰져야 한다는 관점에서 출발하여, 시니어의 언어와 건강 상태, 사용 환경을 고려한 AI 건강 식생활 서비스를 제공합니다.

## 우리가 해결하려는 문제

고령층은 작은 글씨와 복잡한 UI, 어려운 입력 방식 때문에 디지털 서비스를 이용하는 데 큰 어려움을 겪습니다. 특히 사투리나 생활 언어를 사용하는 경우 기존 AI가 질문을 제대로 이해하지 못하며, 음식 이름과 건강 정보를 스스로 판단하기도 어렵습니다. 또한 인터넷에는 검증되지 않은 건강 정보가 많아 잘못된 정보를 믿을 위험도 존재합니다. SilverLens는 사용자의 말투와 생활 언어를 이해하고, 음식 사진과 건강 정보를 함께 분석하여 누구나 쉽고 안전하게 건강 식생활 정보를 이용할 수 있도록 돕는 것을 목표로 합니다.

# SilverLens 차별점

SilverLens는 단순히 AI 기능을 제공하는 것이 아니라, **어르신이 실제로 쉽고 안전하게 사용할 수 있는 경험**을 목표로 설계된 시니어 맞춤형 AI 서비스입니다.

기존 AI와 비교했을 때 SilverLens는 사용자의 언어, 건강 상태, 디지털 사용 환경을 함께 고려하여 누구나 쉽게 사용할 수 있는 AI를 제공합니다.

| 구분 | 기존 AI | SilverLens |
|------|---------|------------|
| **사투리 이해** | 표준어 중심 음성 인식(STT) | 사투리와 생활 언어까지 이해하여 자연스럽게 해석 |
| **멀티모달 건강 분석** | 음식 또는 이미지 인식 중심 | 텍스트·음성·음식 사진과 건강 정보를 함께 분석 |
| **건강정보 활용** | 질문마다 개별 처리 | 질병·알레르기·건강 메모를 지속적으로 반영 |
| **검색 방식(RAG)** | 전체 데이터를 프롬프트에 포함하거나 단순 검색 | 질문과 관련된 음식·재료·별칭·안전 규칙만 선별하여 검색 |
| **음성 안내(TTS)** | 단순 음성 변환 | 첫 음성 우선 생성, 선행 로딩, 캐시, 자동 이어 읽기 지원 |
| **시니어 UI/UX** | 일반 사용자 중심 인터페이스 | 큰 글씨, 단순한 화면, 음성 중심의 시니어 맞춤 UI/UX |
| **다국어 건강정보 관리** | 문자열 번역 중심 | 고유 ID 기반 건강정보 관리로 언어 변경 시에도 정보 일관성 유지 |
| **건강 안전성** | 일반적인 답변 제공 | 알레르기·질병 정보를 기반으로 위험 식품을 우선 경고 |
| **응답 성능 최적화** | 요청마다 AI 생성 | 모델 폴백, 답변 캐시, 음성 캐시, 서버 메모리 캐시 적용 |
| **신뢰성** | AI 판단에 의존 | 공개 건강 데이터와 자체 안전 규칙을 함께 활용하여 답변 생성 |

# SilverLens의 핵심 기능

**1. 사투리 찰떡 음성 인식**
<br>저희는 기술이 인간의 고유한 언어와 흔적을 존중해야 한다고 생각합니다. 기존 AI는 표준어로 정확하게 발음하지 않으면 쉽게 알아듣기 어렵습니다. SilverLens는 평생의 삶이 담긴 사투리와 생활 용어를 사전으로 정리해 음성 인식 단계부터 함께 넘겨 줍니다. 그래서 어르신이 "이 정구지 어째 먹노?"라고 투박하게 말씀하셔도 그 안에 담긴 속뜻을 이해하고 손주처럼 다정하게 답변합니다.

**2. 돋보기 카메라**
<br>지식의 나열보다 중요한 것은 한 사람을 향한 안전과 보호입니다. 기존 AI는 단순히 사진 속 사물의 이름만 딱딱한 데이터로 보여주고 끝냅니다. SilverLens는 사진을 찍기 전에 **무엇을 찍는지**(성분표·음식·약 봉투) 먼저 고르게 해서 볼 곳을 좁히고, 낯선 외래어를 쉬운 우리말로 풀어 줍니다. 여기에 등록한 질병·알레르기와 자체 식품 지식 데이터를 함께 대조해 "이 음식은 당뇨에 안 좋으니 조금만 드세요" 같은 건강 맞춤형 경고를 전달합니다.

**3. 간단한 UI/UX와 다정한 음성 안내**
<br>복잡한 메뉴와 카테고리는 어르신들에게 기술에 대한 두려움만 심어줄 뿐입니다. SilverLens는 어르신들의 인지 특성을 고려하여 화면 구성을 직관적으로 단순화하고 글자 크기를 키웠습니다. 답변 음성은 "또박또박하고 따뜻하게 읽어 달라"는 지시와 함께 생성하고, 어르신이 직접 읽기 속도를 조절할 수 있게 했습니다. 기계에 맞추는 것이 아니라 사람에게 맞추는 방향입니다.

**4. 코드가 보장하는 안전 하한선**
<br>AI의 판정만 믿지 않습니다. 등록한 질병과 위험 식품이 함께 걸리면 코드가 위험도의 최소값을 보장해서, 모델이 위험을 낮게 매겨도 화면에는 경고가 남습니다.

## 방언 처리

| 항목       | 내용                                                          |

| 사전 활용 방식 | 사투리 사전 257개를 음성 인식 단계부터 함께 넘겨 사투리를 표준어로 알아듣게 함              |
| 우선순위     | 식재료 · 음식 · 신체증상 항목을 먼저 넘겨 건강 대화에서 중요한 어휘가 빠지지 않게 정렬          |

| 별도 설치    | 필요 없음. 저장소를 받은 그대로 동작함                                      |
| 지역 확장    | `data/sources/dialect_dictionary.csv` 에 지역 말을 추가하고 변환 스크립트를 돌리면 반영 |

### 제주 방언 대응 (선택 구성요소)

제주 방언에 특화된 `sjbaek/gemma2-2b-it-korean-dialect`(MIT) 를 로컬 변환 서버로
함께 두었습니다. `backend/local_dialect` 에 있고 `NEXT_PUBLIC_DIALECT_API_URL` 을 설정했을
때만 호출합니다.

기본 동작은 위의 사전 경로만으로 완결됩니다. 로컬 서버가 없거나 응답이 늦으면 원문을 그대로
쓰고 사전 경로가 이어받으므로, 이 구성요소가 없어도 서비스는 동일하게 동작합니다.

## AI 답변 음성(TTS)

| 항목       | 내용                                                                 |
| -------- | ------------------------------------------------------------------ |
| 음성 생성 방식 | 긴 답변을 여러 개의 짧은 문장 묶음으로 동시에 생성                                      |
| 읽기 지시    | "어르신께 또박또박하고 따뜻하게 읽어 달라"는 지시를 함께 보내 말투를 맞춤                         |
| 읽기 속도    | 어르신이 직접 조절하고 선택한 속도를 브라우저에 저장                                      |
| 음성 캐시    | 생성된 음성을 브라우저 메모리에 저장하여 같은 답변은 다시 변환하지 않고 재사용                       |
| 서버 음성 캐시  | 서버도 만든 음성을 30분 · 최대 20MB 범위에서 보관하여 같은 문장은 즉시 응답                     |
| 답변 표시 방식 | 큰 글씨 카드 형태로 표시                                                     |
| 카드 구성    | 왼쪽은 이전 대화, 오른쪽은 이어지는 답변 및 새로운 대화                                   |
| 자동 재생    | 현재 카드의 TTS가 끝나면 다음 카드로 자동 이동하여 이어서 재생                              |
| 예비 음성    | Gemini TTS 요청 실패 또는 API Key가 없으면 Web Speech API 기반 브라우저 TTS로 자동 전환 |
| 자동 이동 지원 | 예비 음성(TTS) 사용 시에도 카드 자동 이동 기능 동일하게 지원                              |

# 디지털 세상의 소외를 지우는 빛, SilverLens
> **저희가 생각하는 가장 좋은 기술은 인간을 가르치려 들지 않고, 가장 낮은 곳에서 인간을 닮아가는 기술이라고 믿습니다.**

<br>**기술이 고도화될수록 소외받는 어르신들이 생겨난다면, 고등학생인 저희가 배운 기술로 그 격차를 가장 따뜻하게 메워보고 싶습니다.** 대한민국 모든 어르신들이 타인의 도움 없이도 당당하고 안전하게 디지털 세상을 누릴 수 있도록, 저희 SilverLens 팀은 기술에 마음을 담는 발걸음을 멈추지 않겠습니다.
